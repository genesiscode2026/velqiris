Five-minute setup

Run it before every pull request and release.

The target process is spawned directly with shell: false. Action inputs are passed through environment variables rather than interpolated into a shell command.

name: VELQIRIS MCP Release Gate
on: [push, pull_request]

jobs:
  mcp-release-gate:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: "22"
      - uses: genesiscode2026/velqiris@v1
        with:
          command: node
          args: ./dist/server.js --stdio
          fail-on-review: "true"

What VELQIRIS proves

Reviewable local evidence.

VELQIRIS records observable stdio behavior, schema structure, request correlation, output framing, bounded capture, selected secret patterns, and selected static source patterns.

What it does not prove

  • absence of vulnerabilities;
  • formal security, legal, or compliance certification;
  • dependency provenance or SBOM coverage;
  • complete semantic safety of every tool;
  • production behavior outside the tested command and environment.
