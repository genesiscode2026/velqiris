Step 1 · 5-Minute GitHub Actions Setup

Copy into your workflow. See your verdict before spending a cent.

Runs locally on your own runner with zero telemetry phone-home and zero code leaving your repository.

name: Velqiris MCP Release Gate
on: [push, pull_request]

jobs:
  mcp-release-gate:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: "22"
      - run: npm ci && npm run build
      - name: Run Velqiris Free Release Gate
        uses: genesiscode2026/velqiris@v1
        with:
          command: node
          args: |
            ./dist/server.js
            --stdio
          output: ./velqiris-gate-summary
          fail-on-review: "false"
ACTION INPUTS · SHELL-FREE

Safe argument forwarding

All 5 action inputs pass via environment variables into Node.js and spawn your server with shell: false — flags starting with -- never touch a shell.

  • command: executable (node, npx, python3)
  • args: forwarded tokens, including --stdio or --port=3000
  • source: optional directory for bounded static audit (commercial bundle)
  • output: artifact directory (gate-summary.json / SHA-256 bundle)
  • fail-on-review: set "true" to block PRs on REVIEW
