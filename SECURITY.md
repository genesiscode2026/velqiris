# Security policy

## Supported release

Security fixes are applied to the current `v1` release line.

## Reporting a vulnerability

Email `chitara.trading@proton.me` with the affected version, reproduction steps, impact, and any suggested mitigation. Do not include live credentials or production customer data. Please avoid a public issue until a fix or coordinated disclosure date is agreed.

VELQIRIS reports are diagnostic evidence, not a security certification or guarantee that a target contains no vulnerabilities.
