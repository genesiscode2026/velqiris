# Reproducible VELQIRIS demonstrations

These examples show observable before-and-after behavior. Every credential-like value is synthetic and assembled at runtime so it cannot be mistaken for a usable secret.

| Case | Broken result | Corrected result | What changes |
| :--- | :--- | :--- | :--- |
| Schema drift | `FAIL` | `PASS` | `inputSchema.type` changes from `string` to `object`. |
| Stdout framing | `REVIEW` | `PASS` | A non-JSON log line is removed from the stdio protocol channel. |
| Secret exposure | `FAIL` | `PASS` | A synthetic token is no longer written to stderr. |

## Run the public gate

From the repository root:

```bash
node gate/action-runner.js
```

The composite Action is the normal public entry point. For direct local reproduction with the commercial bundle:

```bash
node /path/to/velqiris/bin/chitara-mcp-assure.js \
  --command node \
  --arg ./demos/schema-drift/broken-server.js \
  --output ./demos/schema-drift/captured/broken
```

Repeat with `fixed-server.js`, or use the corresponding servers in `stdout-framing` and `secret-exposure`.

## Captured evidence

Each `captured/` directory contains sanitized `report.json`, `report.md`, and `manifest.sha256.json` generated by the commercial bundle. Timestamps are real generation timestamps; results should be semantically identical when rerun, while timestamps and hashes may change.

The free gate does not include `SECRET_EXPOSURE`, so the secret-exposure case is intentionally demonstrated with the commercial bundle.
